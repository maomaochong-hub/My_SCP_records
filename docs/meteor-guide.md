# 流星与动效：逐条验证手册

> 适用：本机 Windows，仓库在 `M:/SCP`，Node ≥ 20。
> 每一步都写了「输入什么」和「应该看到什么」。某一步对不上，直接跳到第 10 节对照。

---

## 0. 先记住三个地址开关

地址栏后面加这些参数，能立刻改变流星的行为，不用改任何代码：

| 地址 | 作用 | 什么时候用 |
|---|---|---|
| `http://127.0.0.1:8787/` | 正常模式 | 日常看 |
| `http://127.0.0.1:8787/?meteors=test` | **密集模式**：每 0.7–1.1 秒一颗，大流星概率 50% | 想立刻确认「流星、大流星、照亮、吞噬」都正常 |
| `http://127.0.0.1:8787/?meteors=on` | 忽略系统的「减少动效」设置，按满速播放 | 系统关了动画，但你想看完整效果 |
| `http://127.0.0.1:8787/?meteors=off` | 完全关闭流星 | 录屏、截图、省电 |

---

## 1. 启动服务

**打开：** Windows 终端（PowerShell 或 Git Bash 都行）

**输入：**

```powershell
cd M:/SCP
npm run dev
```

**应该看到：**

```
> scp-terminal@2.0.0 dev
> node --watch server/server.js

SCP terminal  http://127.0.0.1:8787
```

最后一行是启动成功的标志，它会一直停在那里不动（这是正常的，服务在前台跑着）。

**如果看到的是：**

```
[x] 端口 8787 已被占用（PID 12345 · node.exe）。
```

说明上一次没关干净。按它给的命令结束那个进程，然后重新 `npm run dev`：

```powershell
Stop-Process -Id 12345 -Force
```

> 这个终端窗口要一直开着。关掉窗口 = 服务停止 = 浏览器打不开页面。

---

## 2. 打开页面

**打开浏览器（Chrome / Edge），地址栏输入：**

```
http://127.0.0.1:8787/
```

> ⚠️ 一定用 `127.0.0.1`，不要用 `localhost`。你这台机器的代理会拦 `localhost`，表现为 502 或一直转圈。

**应该看到（从上到下）：**

1. 左上角一行小字 `SCP FOUNDATION / PERSONAL TERMINAL`，右上角一个 `登录` 按钮；
2. 中间偏上：巨大的 `S_C_P` 三个字母，字母之间有短横线；
3. 字标正下方，一行**红色**的 `[ 此网站已被标记为待删除 ]`；
4. 画面正中：一个倒三角形的递归徽记，中心叠着一行小字 `Per Aspera Ad Astra`；
5. 这行字的**左下角**和**右上角**各有一个半角方框（L 形细线）；
6. 页面在 8 片竖向黑幕拉开后出现（约 0.6 秒）。

---

## 3. 确认流星（打开后 5 秒内一定看得到）

**你要做的：什么都不用做，盯着画面看。**

**应该看到：**

- 打开约 **1.4 秒**后，第一颗流星从**画面中央上方**斜着落下（往左下飞），尾巴朝右上；这一颗被特意安排成「从中央掠过」，就是为了让你确认它存在；
- 之后每 **1.7–4.2 秒**出现一颗新的，画面上最多同时 3 颗；
- 每颗流星：**头部一个亮点（带十字星芒，会轻微呼吸）+ 一条向上渐隐的尾巴**，与水平面约 10°–34° 的斜角。

**如果 10 秒过去什么都没看到 → 直接跳到第 8 节，运行 `SCP_METEORS.diagnose()`。** 不要猜。

---

## 4. 看大流星与「照亮文字」

大流星不是每次都有：概率 18%，且两颗之间至少隔 18 秒 → **平均 20–40 秒一颗**。等不及就用密集模式。

**方式 A（推荐，快）：** 地址栏改成

```
http://127.0.0.1:8787/?meteors=test
```

**方式 B（真实节奏）：** 就停在普通页面，最多等 40 秒。

**应该看到：**

1. 一道**更粗、更快**的流星，头部裹着一团柔和光晕；
2. 当它经过中央那行 `Per Aspera Ad Astra` 时——**整行字变白、变亮，周围一小片区域也跟着亮起来**；字标 `S_C_P` 和红色标签如果在光斑范围内，也会一起被提亮；
3. 光飞过去后，文字**自己慢慢暗回原来的灰度**（不是瞬间切回）。

**关键点：** 这不是「在字上面盖一个光斑」。被照亮的是**文字本身**——`.glare` 是一份整页内容的白色克隆层，用跟随流星的径向遮罩只露出一个小圆，所以是字变白，不是糊一层雾。

---

## 5. 看「吞噬」

大流星飞行路径上如果碰到小流星，小流星会**当场消失**，并闪一下。

**你要做的：** 在 `?meteors=test` 模式下盯着看 10–20 秒。

**应该看到：** 小流星被大流星追上的那一瞬间，先闪一个白点（0.26 秒内扩散消失），随即整颗小流星没了。

> 判定半径 52 像素。这是概率事件，看一两分钟没撞上也正常，不是坏了。

---

## 6. 次页：没有流星，只有三个入口

**你要做的：** 把鼠标移到 `Per Aspera Ad Astra` 上，然后点它。

**应该看到：**

1. 悬停时：字距**缓缓拉开**，字变亮，下方浮出一条细线，两个角框**放大并向外扩**（15px → 25px）；
2. 点击后：8 片幕布收拢 → 页面切换 → 幕布展开，落到 `/stage/`；
3. 次页的**顶部完全一样**（元信息、`S_C_P`、红标），只是中央那行拉丁句**换成了三个竖排入口**：
   - `01 项目收集 Collection · N 个项目 · M 个分类`
   - `02 灵感写作 Notes · N 张便签 · 含网页创作`
   - `03 其他 Misc. · 未编目 · 占位`
4. **次页没有任何流星，也没有星尘**——这是设计如此。

**想验证：** 在次页按 `F12` → `Console`，输入

```js
document.querySelectorAll('.meteor').length
```

**应该返回：** `0`

回到首页 `/` 再运行一次，返回 `0` 到 `3` 之间变化的数字（说明引擎在跑）。

## 7. 系统开了「减少动效」会怎样

Windows 设置里关掉「动画效果」，浏览器就会告诉网页「用户偏好减少动效」。

**以前的行为（已修掉的 bug）：** 什么都不生成，也不给任何提示——这就是你「完全看不到流星」的最可能原因。

**现在的行为：**

| | 正常模式 | 减少动效模式 |
|---|---|---|
| 有没有流星 | 有 | **有**（不会再消失） |
| 间隔 | 1.7–4.2 秒 | 3.8–7.2 秒 |
| 速度 | 原速 | 0.55 倍（更缓） |
| 同时在飞 | 最多 3 颗 | 最多 2 颗 |
| 大流星 | 18% / 间隔 18 秒 | 9% / 间隔 26 秒 |

想按满速看：用 `?meteors=on`。想永久恢复：Windows 设置 → 辅助功能 → 视觉效果 → 打开「动画效果」。

## 8. 三条控制台命令（出问题先跑第一条）

**打开：** 在页面上按 `F12`（Edge 也是 F12），点上方 `Console` / `控制台` 标签。

**输入并回车：**

```js
SCP_METEORS.diagnose()
```

**正常时应该看到（逐行）：**

```
SCP 流星诊断
·页面: /
[OK]  系统偏好减少动效: 否
[OK]  找到了 .meteor-field: 是
[OK]  舞台尺寸: 1440 × 869
[OK]  舞台 position: absolute
[OK]  舞台 display: block
[OK]  找到了 .glare 照亮层: 是
[OK]  引擎已挂载: 是
·未挂载原因: （无）
·当前流星数: 1
·常驻星尘数: 16
·地址栏开关: （无）
结论：正常，画面里现在有 1 颗流星在飞。
```

**几种「不正常」的输出和含义：**

| 输出 | 含义 | 怎么办 |
|---|---|---|
| `[!!] 舞台尺寸: 0 × 0` | 流星层被压成零尺寸，画不出任何东西 | 说明 CSS 又被改坏了，`meteor.css` 里不要出现 `display:none` |
| `[!!] 找到了 .meteor-field: 否` | 你在次页 `/stage/` | 回首页，次页设计上没有流星 |
| `[!!] 未挂载原因: 页面上没有...` | 引擎没启动 | 输入 `SCP_METEORS.start()` |
| `·当前流星数: 0` 但其它都 OK | 正好在两颗之间 | 输入下一条命令 |

**第二条：立刻放三颗**

```js
SCP_METEORS.burst(3)
```

**应该看到：** 画面里同时出现 3 颗流星（第 1 颗是大流星，带光晕），返回值 `3`。

**第三条：强制启动（引擎没挂上时用）**

```js
SCP_METEORS.start()
```

**应该看到：** 控制台打印 `已强制启动流星（忽略系统的减少动效设置）。`

## 9. 想调参数？改这几个地方

**打开文件：** `M:/SCP/public/assets/js/modules/meteors.js`（用 VS Code：`code public/assets/js/modules/meteors.js`）

| 第几行 | 常量 | 现在的值 | 改了会怎样 |
|---|---|---|---|
| 19 | `BIG_RATE` | `0.18` | 大流星出现的概率。调到 `0.5` 会非常频繁 |
| 20 | `BIG_COOLDOWN` | `18000` | 两颗大流星的最小间隔（毫秒）。调到 `6000` = 6 秒 |
| 21 | `EAT_RADIUS` | `52` | 吞噬判定半径（像素）。调大更容易撞上 |
| 23 | `LIGHT_R` | `380` | 照亮半径。调大 = 离得远也开始提亮 |
| 24 | `GAP` | `[1700, 4200]` | 小流星的间隔区间（毫秒）。想更密就 `[800, 1800]` |
| 25 | `FIRST_AT` | `1400` | 打开页面后第一颗的时间（毫秒） |
| 62 | `gap`（soft 分支） | `[3800, 7200]` | 系统「减少动效」时的间隔 |

**改完怎么生效：** 直接刷新页面（`F5`）就行。开发环境已经把静态文件改成 `no-cache`，不需要 `Ctrl+Shift+R` 强制刷新，也不用重启服务。

**如果改的是 `server/` 下的文件**：`npm run dev` 用的是 `node --watch`，保存后会自动重启，终端里会多一行重启日志。
**如果改的是 `.env`**：不会自动重载，必须 `Ctrl+C` 停掉再 `npm run dev`。

## 10. 故障对照表

| 现象 | 最可能的原因 | 动作 |
|---|---|---|
| 页面完全打不开 / 502 | 用了 `localhost`，或被系统代理拦截 | 换成 `127.0.0.1:8787`；确认终端里服务还在跑 |
| 页面能开，但看不到流星 | 系统「减少动效」已开启（旧版本会直接不画） | 现在按第 7 节应该仍有；若没有，跑 `SCP_METEORS.diagnose()` |
| `diagnose()` 说舞台 `0 × 0` | CSS 里有人把 `.meteor-field` 设成了 `display:none` | 打开 `meteor.css`，删掉那条规则；只允许 `html.meteor-off` 时隐藏 |
| 流星一闪就没 / 只在顶部出现 | 正常：飞行时间约 0.7–1.5 秒，起点在画面上缘外 | 无 |
| 看不到大流星 | 概率 18% + 间隔 18 秒，平均 20–40 秒一颗 | 用 `?meteors=test` |
| 文字没被照亮 | 大流星那次没掠过句子（62% 才会刻意瞄准） | 用 `?meteors=test` 多等几颗 |
| 次页什么动效都没有 | 设计如此：次页没有流星 | 回首页 |
| 改了代码刷新没变化 | 浏览器缓存了旧文件 | 开发环境已改 `no-cache`；老页面按一次 `Ctrl+Shift+R` |
| 控制台报 `SCP_METEORS is not defined` | 你在次页，或脚本没加载完 | 回到首页；等 1 秒再输 |
| 整个页面全黑，只剩背景色 | 极少数情况：入场动画基态被卡住 | 现在默认可见，不会白屏；若出现按 `Ctrl+Shift+R` |
